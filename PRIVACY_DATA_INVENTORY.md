## Current analytics boundary

CornellPulse has no third-party browser analytics SDK in this repository. Optional resource-click events are first-party database records. They exclude names, email addresses, check-in text, and a CornellPulse account identifier, but the project has not established that infrastructure metadata cannot be identifying.

The separate product-measurement plan currently stays on-device. With explicit consent it counts check-in completions, resource-action types, successful-contact answers, and repeat saves. It does not record event timestamps, resource identifiers, raw answers, free text, names, emails, or phone numbers. Any future upload of these counters requires a new documented data-flow review; the current consent copy does not authorize transmission.
